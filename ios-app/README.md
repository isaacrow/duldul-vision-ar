# دلدل Vision AR — Native Apple RealityKit & ARKit 6 Project
### تطبيق آيفون متكامل للملاحة ثلاثية الأبعاد (Native iOS SwiftUI + RealityKit + ARKit + CoreML)

تم بناء هذا التطبيق الأصلي للآيفون لكسر جميع قيود متصفح الويب والاستفادة الكاملة من عتاد ومستشعرات أبل الحصرية:
1. **مستشعر Apple LiDAR و ARKit 6 الحقيقي (Scene Mesh Reconstruction):**
   - بناء شبكة ثلاثية الأبعاد للشارع والمحلات والمركبات لحظياً بدقة المليمتر.
   - قراءة مسافة العمق الحقيقية بالأمتار باستخدام مستشعرات `ARFrame.sceneDepth` و `smoothedSceneDepth`.
2. **محرك الواقع المعزز Apple RealityKit 4 و Metal:**
   - إسقاط أسهم توجيه مجسمة ثلاثية الأبعاد (Holographic Floor Chevrons) تتوهج على أسفلت الشارع لترشد السائق إلى مساره.
   - تثبيت شارات زجاجية عائمة ثلاثية الأبعاد على واجهات المحلات والشواخص فور قراءتها.
3. **معالج الذكاء الاصطناعي Apple Neural Engine (NPU):**
   - قراءة شواخص المرور وأسماء المحلات بالعربية والإنجليزية لحظياً بسرعة 60 إطاراً في الثانية دون استهلاك المعالج الرئيسي عبر `VNRecognizeTextRequest`.
4. **شاشة تسلا ثلاثية الأبعاد (Tesla FSD V12 3D Vector Space):**
   - محاكاة حية مطابقة لصور شاشة تسلا: سيارة السائق الزرقاء في المقدمة مع شريط التوجيه الأزرق المتوهج، والمركبات والشاحنات المحيطة تتحرك في 4 مسارات ثلاثية الأبعاد، وعداد السرعة العريض وشارة السرعة القصوى `100 MAX` وشريط ناقل الحركة `PRND`.
5. **نظام الملاحة والتوجيه الصوتي باللهجة العراقية (Turn-by-Turn GPS):**
   - تتبع فائق الدقة للسيارة عبر `kCLLocationAccuracyBestForNavigation`.
   - توجيه صوتي حقيقي باللهجة البغدادية الأصيلة ("ورا 300 متر لوف يمنة"، "امشي كبل"، "دير بالك سيطرة أمنية كدامك"، "وصلت بالسلامة يا غالي").
6. **رادار جسور بغداد اللحظي (10 Tigris Bridges Radar):**
   - رصد حي لحالة وسرعة الجسور (الجادرية، السنك، الأحرار، الشهداء، الصرافية، باب المعظم، 14 رمضان، المثنى، المعلق، الدباش) مع تحديد الجسر الأسرع تلقائياً.
7. **إبلاغ وتنبيهات السائقين (Community Hazards & Speed Cameras):**
   - تنبيه صوتي فوري عند الاقتراب من سيطرة أمنية أو كاميرا مراقبة سرعة بمسافة 400 متر.
   - زر إبلاغ سريع بكبسة واحدة أثناء القيادة مع نقاط مكافأة للكابتن (+50 نقطة).

## هيكلية الأكواد والمجلدات (Project Architecture)

```
ios-app/DuldulVisionAR/
├── Package.swift                             # تعريف حزمة Swift Package Manager
├── Info.plist                                # أذونات الكاميرا ومستشعر LiDAR والموقع الجغرافي
└── Sources/
    ├── App/
    │   └── DuldulVisionARApp.swift           # نقطة تشغيل التطبيق وتوزيع الـ Services
    ├── Models/
    │   └── SpatialAnchorModel.swift          # نموذج الإحداثيات والبيانات المكانية (X, Y, Z)
    ├── Services/
    │   ├── ARKitVisionManager.swift          # مدير تتبع ARKit وعمق LiDAR وأسهم الواقع المعزز
    │   ├── NavigationManager.swift           # محرك الملاحة ونظام التوجيه الصوتي العراقي
    │   ├── IncidentManager.swift             # رادار ورصد الحوادث وكاميرات السرعة والسيطرات
    │   ├── BridgesManager.swift              # رادار جسور بغداد وحركة نهر دجلة
    │   └── SpatialCatalogService.swift       # مزامنة البيانات المكانية مع خادم دلدل الملاحي
    └── Views/
        ├── ContentView.swift                 # الحاوية الرئيسية وشريط التبديل السفلي وشريط التنبيهات
        ├── TeslaFSDVectorSpaceView.swift     # فضاء تسلا ثلاثي الأبعاد (مطابق للصور)
        ├── SpatialARScannerView.swift        # كاميرا الواقع المعزز RealityKit مع أسهم الشارع
        ├── MapNavigationView.swift           # الخريطة الداكنة مع الشرايين الكهرمانية والمعالم
        ├── ReportHazardSheet.swift           # نافذة الإبلاغ المباشر بكبسة واحدة
        └── BridgesRadarSheet.swift           # قائمة مؤشرات ورادار جسور بغداد
```

## طريقة الفتح والتشغيل في Xcode:

1. افتح برنامج **Xcode** على جهاز Mac.
2. يمكنك النقر المزدوج مباشرة على ملف المشروع:
   `DuldulVisionAR.xcodeproj`
   أو اختر **File -> Open** وحدد مسار المجلد:
   `ios-app/DuldulVisionAR`
3. قم بتوصيل هاتف الآيفون بالكيبل، واختر اسم هاتفك في شريط الأجهزة بالأعلى.
4. اضغط على زر **Run (⌘ + R)** ليبدأ البناء والتثبيت المباشر على جهازك.
